# Memory Game

Um jogo da memória inspirado no universo do filme **Carros**, da Pixar, desenvolvido para praticar manipulação do DOM, lógica de programação e interatividade utilizando **HTML**, **CSS** e **JavaScript**.

## ✨ Demonstração

https://anaclrsnts.github.io/projeto_memory_game/

## 📌 Funcionalidades

* Geração aleatória das cartas a cada partida.
* Contador de movimentos.
* Cronômetro em tempo real.
* Detecção automática de pares.
* Tela de vitória ao finalizar o jogo.
* Reinício da partida com um novo embaralhamento.

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript (ES6)

## 🎮 Como jogar

1. Clique em **Start Game**.
2. Vire duas cartas por vez.
3. Encontre todos os pares correspondentes.
4. Complete o jogo no menor tempo e com o menor número de movimentos possível.
